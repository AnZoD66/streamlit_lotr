The Lord of the Rings Watch Reminder 🧙‍♂️ An interactive Streamlit app inspired by The Lord of the Rings. It helps users keep track of when they last watched the trilogy and includes an interactive Tolkien book tracker and quiz.

Features 📅 Record the date of your last Lord of the Rings watch

⏳ Get a reminder based on how long it has been since your last watch

📚 Search and add Tolkien books you have read

🔎 Fuzzy book search using RapidFuzz

📊 Display your books using Pandas

🧠 Unlock a Tolkien quiz after adding more than 3 books

🎲 Randomised quiz questions with Easy, Extra, and Advanced difficulties

💡 Hints for quiz questions

🏆 Score tracking and different results based on performance

🔄 Restart the quiz and try again

Technologies Python

Streamlit — user interface and application logic

Pandas — displaying the user's book list

RapidFuzz — fuzzy matching for book searches

Python datetime — calculating watch intervals and dates
